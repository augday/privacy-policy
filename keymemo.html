2. 总体原则

  • 无自有「密码云」：本应用不以运营方自有服务器集中存储您的密码条目内容作为产品设计目标。密码及相关数据主要保存在您的设备上，并在您开启相关能力时依赖 Apple 系统提供的钥匙串 / iCloud 钥匙串等机制（详见下文）。
  • 无第三方广告与分析 SDK：当前版本未集成常见的第三方广告网络、用户行为分析或崩溃上报 SDK（如 Firebase Analytics、友盟等）。若未来版本有变更，我们将更新本政策并在应用内或 App Store 说明中提示。
  • 最小化：仅在实现功能所必需的范围内处理信息；敏感操作尽量在设备本地完成。

3. 我们处理哪些信息、用于什么目的

3.1 您主动输入与生成的内容（密码库数据）

包括但不限于：账号标题、用户名、密码、网址、备注、分类、标签、收藏状态等您在应用内录入或导入的数据。

  • 目的：提供密码管理、搜索、编辑、安全检查、导入导出等核心功能。
  • 存储位置：
    • 本地：数据通过系统 Keychain（钥匙串）相关接口在设备上加密存储；具体加密与访问控制由 iOS / Apple实现。
    • 可选 iCloud 同步：若您在应用内开启 iCloud 同步（且为 Premium 等应用规则所允许），数据可能通过 iCloud 钥匙串在登录同一 Apple ID 的设备间同步。该过程由 Apple提供，受您的 Apple ID、系统「密码与钥匙串」等设置约束；运营方无法访问您的 iCloud 内容。
  • 保存期限：在您删除应用、清除数据或删除相应条目之前持续存在；删除行为受系统与应用逻辑影响，请以应用内实际行为为准。

3.2 主密码与生物识别

  • 主密码：用于保护您的密码库；以加密相关形式参与本地/钥匙串存储逻辑，不会以明文形式发送给运营方服务器（本应用不运营用于接收主密码的自有后端）。
  • Face ID / Touch ID：用于在设备上便捷解锁应用及授权敏感操作。生物特征数据由 Apple在设备安全区域内处理，本应用无法读取您的原始指纹或面容数据。
  • 系统权限文案：与本应用请求的系统权限（如 Face ID 使用说明）以 App Store 展示及系统弹窗为准。

3.3 应用偏好设置（非密码内容）

例如主题色、应用图标选择、自动锁定时间、剪贴板自动清除时间、是否开启 iCloud 同步开关等，可能保存在设备上的 UserDefaults等本地存储中。

  • 目的：记住您的界面与安全相关偏好。
  • 此类数据通常不包含您的密码条目明文。

3.4 剪贴板

当您使用「复制」功能时，相关内容会写入系统 剪贴板（Pasteboard）。若您启用了剪贴板自动清除选项，本应用会按您设定的时间尝试清除剪贴板中的对应内容（具体行为以系统 API 与 iOS 版本为准）。

  • 目的：方便您粘贴到其他应用，并降低敏感信息长时间留在剪贴板的风险。
  • 注意：剪贴板可能被同一设备上的其他应用读取（取决于系统与其他应用行为），请勿在不可信环境中复制高敏感信息。

3.5 应用内购买（Premium）

Premium 等功能通过 Apple StoreKit完成购买与恢复。交易信息与 Apple ID 关联部分由 Apple处理；本应用可能仅在设备本地获知购买状态（例如是否已解锁 Premium），运营方不接收您的完整银行卡号（支付由 Apple 处理）。

3.6 设备环境检测（本地）

为降低在已被越狱等环境下使用密码管理器的风险，本应用可能包含设备环境检测逻辑；该检测在设备上完成，不以识别自然人为目的向运营方服务器上传检测结果（本应用无对应自有接收端）。

3.7 屏幕录制、投屏与截图相关提示

在支持的系统能力下，本应用可能监听与屏幕捕获、截图相关的事件，用于在检测到风险时锁定应用界面，以减少敏感内容被录屏或截屏的风险。相关处理在本地进行。

3.8 导入与导出

当您使用导入、导出或分享功能时，文件会通过您选择的系统分享渠道（如「文件」、AirDrop、其他应用）离开本应用。

  • 目的：备份、迁移或在其他环境使用。
  • 注意：导出文件的安全性取决于您设置的密码、存储位置与接收方；请自行妥善保管。

4. 我们不会主动做的事情（除非本政策另有说明）

  • 不以运营方名义运营可登录的「网页版 KeyMemo」来集中托管您的密码库。
  • 不出售您的密码库数据给数据经纪人。
  • 不将您的密码用于第三方广告画像（本应用无集成此类 SDK）。

5. 与 Apple 的关系说明

本应用分发于 Apple App Store，并依赖 iOS、Keychain、iCloud、StoreKit、LocalAuthentication等 Apple 提供的能力。这些服务受 Apple 隐私政策约束；关于 Apple ID、iCloud、支付等信息的处理，请参阅 Apple 官方说明。

6. 未成年人

本应用处理的密码信息可能涉及敏感个人数据。若您为未成年人，请在监护人指导下使用，并在监护人同意下再进行购买等行为。

7. 您的权利与自我管理

在适用法律允许的范围内，您可以通过以下方式管理信息：

  • 在应用内编辑、删除条目；关闭 iCloud 同步；修改主密码与安全选项。
  • 卸载应用前请确认已备份需要保留的数据；卸载可能导致仅保存在本设备上的数据被清除（具体以系统行为为准）。

不同国家或地区对个人信息权利（访问、更正、删除、可携带、反对处理等）的规定不同；如需行使权利，请通过本文开头的联系方式说明您的身份与请求。

8. 跨境与存储地点

若您使用 iCloud 钥匙串等功能，数据可能经由 Apple 的基础设施在您的账户所选区域策略下存储与同步。运营方不单独将您的密码库迁移至自有境外服务器。

9. 本政策的变更

我们可能因功能更新、监管要求或业务调整而修订本政策。重大变更时，我们将通过更新本页面日期、应用内提示或 App Store 更新说明等合理方式告知。若您在变更后继续使用本应用，即表示您已阅读并接受修订后的政策（在法律要求需单独同意的情形下，以法律规定为准）。
